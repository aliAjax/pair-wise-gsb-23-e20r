# hxwl-09 半导体洁净室巡检

洁净室离线采样回传与批次放行合并看板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

- **离线回传合并**：巡检员离线采样（带采集时点与设备快照）回网后，统一合并房间采样、层流台占用与批次放行单
- **层流台占用冲突**：同一层流台同一时段只能归一个房间，冲突批次接收失败，可释放占用后单独重试
- **字段双版冲突**：以出发基准值做三方合并，同字段两边都改过则保留两版，挂起待下一班确认后才评估放行
- **快照失效重算**：设备校准 / 滤芯维护登记后快照版本递增，引用旧快照的放行结论立即失效并按新快照重算，原始采样记录永久保留
- **幂等接收**：已接收批次重复回传自动拦截；失败批次可单独重试
- **放行门禁**：房间存在未结异常或在室放行容量不足时一律阻断，阻断对象同时列入放行单页面与审计日志
- **审计留痕**：合并、冲突、失效重算、结案、班次切换等全部动作可追溯
